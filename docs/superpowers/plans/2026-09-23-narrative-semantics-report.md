## Changes

- Feedback now uses native, initially empty radio groups with the existing payload field names, fieldsets/legends, 44px labels, and a separate keyboard focus ring. Stable React 19 ref cleanup avoids detached-node retention and protects a newer scene from stale cleanup. No mutation observer, per-word listener, timer, or layout-measurement loop was added. Skip activation only focuses and scrolls the mounted destination.
- The global SkipLink now uses the same focus plus instant-scroll behavior. Main content and the narrative title account for the sticky header. The theme worker made skip links viewport-fixed, revealed them on focus, and removed their reveal transition; the A09 regression below verifies that support.
- Saved Intentions' existing browser regression now seeds deterministic anonymous data, waits for the current journal heading, and exercises nested confirmation focus, tab wrapping, Escape/cancel return, parent trap resumption, deleted-opener fallback, and final return to the journal opener. Production modal changes remain with the root worker.

## Integration regression

The original mid-stream failure regression exposed a particle-canvas lifecycle race after the narrative registration changed rendering timing. A debugger pause in the failing browser captured `Canvas._repairStyle` repeatedly writing canvas styles from a MutationObserver. Removing only ParticleLayer made the unchanged test pass while retaining all narrative headings and skip navigation. Removing the narrative registration also avoided the timing, but was not a valid fix for the required navigation.

The installed particle React adapter reloaded on the whole props object and cleaned up only an already-resolved container. A load resolving after cleanup could leave a canvas observer alive. ParticleLayer now shares one engine initialization promise and owns a serialized canvas session, explicitly passes its DOM host, and destroys cancelled or detached results before allowing a replacement load. Decorative initialization/load failures are handled without interrupting the reading. The original narrative registration implementation is retained.

Four focused lifecycle unit cases pass: pending-load replacement ordering, unmount during engine initialization, failed-load recovery/detached completion, and cleanup of a registered container after startup rejects while preserving unrelated owners. The unchanged original mid-stream browser test passed three consecutive runs (25.6 seconds total). See the [integrated implementation report](2026-09-23-personalized-narrative-remediation-report.md) for the full final regression and gate results. Diagnostic scripts and failed-control traces remain outside the source tree under `C:/Users/htper/.codex/tmp/narrative-isolation-*` and `narrative-pause-probe`; they are not application changes.
The acceptance worker owns full keyboard/payload/error-retention, streaming/focused-mode skip, browser matrix, and rendered evidence. Full suites/builds remain with the root worker to avoid testing across concurrent edits. These focused results are not production, live AI, physical-handset, or screen-reader evidence.
