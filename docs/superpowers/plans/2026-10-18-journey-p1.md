## Regression Repairs

The subsequent regression review reproduced four issues in that implementation. All four now have tests that failed before the repair and passed afterward:

- Warm Worker requests accumulated mutating D1 tracing wrappers, eventually breaking transactional saves. Sentry now wraps the stable binding before OTEL creates its proxies; OTEL owns the global provider. Deferred telemetry exports suppress Sentry tracing to avoid creating spans in ended request contexts. Request and database tracing remain enabled in both systems.
- Case, space/underscore, and Unicode card-name variants could collide in persistent badge keys and roll back unrelated journal mutations. Badge identities now encode exact card names losslessly; publication and completeness diagnostics use the same key. Existing streak badges are replaced by the next reconciliation without a schema migration.
- Opting out of analytics hid journal exports. Both desktop and mobile keep complete-history and filtered exports available while showing the disabled-analytics notice and withholding backfill actions. The incomplete-history guard remains in place.
- Embedding suggestions lost the reading selection when navigation moved to structured filters. Suggestions now retain the distinct source entry IDs from the selected cluster, including when the suggested wording paraphrases the saved narrative.
