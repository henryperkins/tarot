## Status Convention

Use `Type: runbook` and `Status: active` for current setup and release procedures. Dated readiness or verification records use `Status: historical snapshot`. Generated package payloads do not carry repository metadata.

## Generated packages

`openai/submission/1.0.1` through `1.0.3` are generated by `scripts/integrations/package_tableu_plugin.py` and consumed by tests. Do not edit them by hand. See [the submission README](openai/submission/README.md).
