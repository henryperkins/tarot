**Actionable findings**

1. **P1 — Restore a working AI narrative provider.** All three AI providers failed on all six completed cases, as independently recorded in `inference_attempts`. The representative retraction request logged Claude HTTP 400, Modal HTTP 503 and OpenAI HTTP 429 before returning `local-composer`. The same three statuses are present on the immediately preceding version `0c2aaf24-ae15-47c0-936a-65b47541cb0b` at 09:34:58–09:35:13 UTC, well before this deployment. Provider settings were preserved. This establishes that the failure pattern predates the remediation; it does not establish the underlying cause. Error handling intentionally discards upstream response bodies, so these logs cannot distinguish such causes as an invalid Claude request field, Modal service availability, or OpenAI rate versus quota limits. No additional provider calls or configuration changes were made to diagnose them. Reading health returning 200 proves configuration presence, not generation success.

2. **P2 — Turn supplied constraints into useful guidance.** The fallback retains input text but often does not interpret it. A reader requesting a practical writing experiment within two hours on Saturday gets “Hold the complexity without rushing to simplify.” The named career decision preserves both options, yet its comparison focuses on elemental combinations rather than the explicitly supplied income and time constraints. The interview case retains November 6 and Tuesday evening without turning them into a preparation step. These outputs meet some preservation checks but provide limited help with the actual question. A later improvement should connect one optional action to the reader's stated constraints without inventing new facts, timing or obligations.

3. **P2 — Remove internal weights from normal reading text.** All three completed three-card readings say, “The Future position carries a weight of 0.90, so its voice leads the guidance.” The implementation value does not help the reader make a choice and undermines the prose. The text originates in [threeCard.js](../../../functions/lib/narrative/spreads/threeCard.js#L70). This review records the finding; it does not change the deployed code.

4. **P2 — Bound reflection echo and improve fallback readability.** The long-note stress case produces 1,106 words, including all 160 repetitions of the neutral input before the useful late reflection. Preservation is valuable, but reproducing the entire stress input overwhelms the reading. All six completed texts also contain “a honest acknowledgment” and an awkward closing addressed to “Reviewer”; the decision comparison joins several long elemental explanations without clean sentence breaks. Preserve access to the reader's original wording while keeping generated guidance concise and readable.

5. **P3 — Keep deck naming consistent through the synthesis.** Thoth headings use Art and Prudence, and Marseille headings use La Mort, L'Etoile and other selected-deck labels, but subsequent story summaries and pivots fall back to Temperance, Eight of Pentacles, Death and The Star. Canonical aliases are not themselves fabricated imagery; the observed problem is inconsistent reader-facing naming. No RWS-specific scene description was observed in the non-RWS reading bodies reviewed here.
